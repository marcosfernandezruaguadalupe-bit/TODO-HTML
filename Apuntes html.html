En este ultimo tema hemos dado las listas.

Exsiten 2 tipos de listas:

Las ordenadas

Para las listas ordenadas se utiliza la etiqueta < ol > y < li >

Ejemplo:

Programas de televisón;

  1. El telediario
  2. El tiempo
  3. Pasa palabra
  4. El chringito

Las no ordenadas

Para las listas no ordenadas se utiliza la etiqueta < ul > y < li >

Ejemplo:

Marcas de coches;

  • Mercedes
  • Toyota
  • Audi
  • BMW
